# 全球經濟研究閱讀室

以《經濟學人》英文文章索引與繁體中文 AI 導讀，協助研究員快速判斷值得深入閱讀的內容。

網站：<https://hrtechtabf.github.io/economist-research-reader/>

## 目前版本

- 資料來源每週一期，來源庫標示每週五晚更新。
- 目前收錄 2026-08-15 期，共 74 篇文章、19 個欄目。
- 第一版先提供 12 篇研究精選的繁中導讀，其餘文章提供標題、欄目與英文原文入口。
- 繁中內容採「事實初稿 → Humanizer 自然化校修」兩階段產生，並會自動擋下被截斷或篇幅異常的輸出。
- GitHub Actions 於週五下午至深夜多次偵測新期，週六上午再補查；同一期不會重複呼叫 Azure。
- 公開網站不包含 Azure OpenAI 金鑰，也不重新發布英文全文。

網站檔案位於 `docs/`，可直接由 GitHub Pages 發布。
