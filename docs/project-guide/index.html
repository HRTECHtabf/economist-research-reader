〈Nepal flash floods〉反覆未通過篇幅檢查

模型多次產生約52至67字的摘要與37至45字的研究角度。內容相對於短訊已可能足夠，但一般文章規則要求更長，導致12次嘗試後仍失敗。系統依安全規則保留前70篇檢查點，待短文規格調整後只補跑失敗文章，最後完成整期發布。

目前已加入

  • 失敗文章補跑：只重做失敗文章，成功內容沿用檢查點。
  • 暫時性錯誤重試：限流、伺服器及網路錯誤採退避重試。
  • 明確診斷：直接標出卡住文章、原因與處理建議。
  • 自癒補跑：看門狗發現資料落後時可重新觸發更新。
  • 安全寫入：原子寫入檢查點，發布前同步遠端版本。

下一步設計

  1. 改用資訊量判斷：綜合文章類型、段落數與內容量，不只看字元門檻。
  2. 共用一套規則：提示詞、通過判斷與錯誤訊息使用同一份設定。
  3. AI 例外判定：多次失敗時由 AI 對照原文決定是否適用短訊規格，留下紀錄且不為湊字數造背景。
  4. 事故狀態留存：維運頁顯示期數、失敗文章、處理階段與最近結果。
